# 常见问题

[返回首页](../README.md) · [开发文档](DEVELOPMENT.md)

## 图片、音效或动画资源缺失

先运行 git lfs pull，再等待 Unity 导入。LFS 指针不是实际素材；不要手工替换同名资源或重建 .meta。

## 放不下单位

检查已选卡牌、格子是否合法、是否已占用、法力是否足够，以及游戏是否暂停。反馈时提供单位和关卡。

## 最后一关无法进入结束场景

当前已补齐 ThanksScene 的构建条目及跳转后的返回。旧构建仍可能缺失，需用修复后的源码重新构建并实测。

## 编辑器正常，导出后场景缺失

核对 Build Profiles 的有效场景为 MainMenu、Level、ThanksScene，且均启用。只把资源放在 Assets 不代表进入构建。

## Web 游戏没有声音

先在页面内操作并确认浏览器未静音。再检查 LFS 音频与 Unity Console；不要把浏览器播放限制当作音频文件已丢失。

## 仍无法解决

提交 Issue 时附版本或提交、系统环境、复现步骤与脱敏错误。优先提供合成文件，保留原数据与完整日志的本机备份。
